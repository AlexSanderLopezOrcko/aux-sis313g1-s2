Busca Google AI Studio

  
Para que nuestra página pueda hablar con los servidores de Google necesitamos una credencial única y gratuita: la API Key. Todo empieza en «Get a Gemini API Key».

Credencial

En el modal «Crea una clave nueva» asigna un nombre, elige el proyecto y confirma con «Crear clave».

Comunicación

  
Cómo viajan los datos

  
NavegadorHTML + JavaScript

  
GeminiNube de Google

  
Petición POST · Headers + API Key · Body JSON

  

  

  
Respuesta JSON

  
GET
Pide información enviando datos visibles en la URL, y con límite de tamaño.
No sirve para nuestro caso

  
POST
Envía un paquete privado: cabeceras con la API Key y un cuerpo en JSON con la pregunta del usuario.
Lo que usamos con fetch







  
Respaldo automático

  
Un plan B que nadie nota

  

    
1gemini-3.5-flash-lite✕ saturado

    
2gemini-flash-lite-latest✕ falla

    
3gemini-3.5-flash✓ responde

    
4gemini-flash-latestde reserva

  

  
No dependemos de un solo modelo. Definimos un arreglo ordenado: si el primero está saturado o falla, el sistema salta automáticamente al siguiente sin que el usuario note cortes.

  
primero los rápidos (lite),
después los estándar como respaldo

Desglose · configuración

  
Configuración y DOM

  

  

    
const API_KEY = "...";
Guarda la llave secreta en una constante para que no pueda modificarse por accidente.

    
const MODELOS = [ ... ];
Una lista ordenada con los 4 modelos: primero los más rápidos (lite) y, de respaldo, los estándar.

    
document.getElementById("…")
Busca en el HTML los elementos con esos id y los guarda en variables, para leer lo que se escribe y mostrar la respuesta.

  







  
Desglose · eventos

  
Eventos y validación

  

  

    
addEventListener("keydown", async …)
Escucha el teclado sobre el input. async permite pedir datos a internet sin congelar la página.

    
if (event.key !== "Enter") return;
Si no es Enter, se detiene: solo actuamos cuando el usuario confirma.

    
entrada.value.trim()
Captura el texto y elimina los espacios sobrantes al inicio y al final.

    
if (pregunta === "") return;
Evita gastar peticiones si la caja está vacía.

    
recuadro.textContent = "Pensando...";
Limpia la caja y muestra «Pensando...» mientras la solicitud está en proceso.

  







  
Desglose · petición

  
Bucle y fetch POST

  

  

    
for (const modelo of MODELOS) { try {
Recorre los modelos uno por uno; try/catch protege el programa si falla la red.

    
const url = ".../models/" + modelo + …
Construye la dirección de la API insertando el nombre del modelo en turno.

    
await fetch(url, { method: "POST", … })
Envía la petición y espera (await) la respuesta de Google antes de continuar.

    
headers: { … }  body: JSON.stringify(…)
Las cabeceras avisan que enviamos JSON y adjuntan la API Key; el cuerpo empaqueta la pregunta como exige Gemini.

  







  
Desglose · respuesta

  
De la respuesta al recuadro

  

  

    
await respuesta.json()
Convierte la respuesta cruda del servidor en un objeto de JavaScript que podemos manipular.

    
if (respuesta.ok) { … candidates[0] … }
Si la petición fue exitosa (HTTP 200), recorre el árbol de la respuesta hasta extraer el texto generado.

    
replaceAll("**", "")  return;
Quita los asteriscos de Markdown, muestra el texto limpio y sale para no probar más modelos.

    
catch (error) { ultimoError = … }
Si un modelo o la red fallan, se guarda el motivo y el bucle sigue con el siguiente; si todos fallan, se muestra el error.

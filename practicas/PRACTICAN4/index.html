Objetivo

Repasar y aplicar los contenidos desarrollados durante las clases de Diseño y Programación Digital, mediante una serie de ejercicios prácticos de HTML y JavaScript.

Durante la práctica se trabajará con:

Estructura básica de HTML Párrafos Imágenes Enlaces Listas ordenadas y desordenadas Tablas JavaScript Eventos Manipulación del DOM Consumo de APIs mediante fetch PokeAPI

La práctica se realizará de forma individual utilizando Git y GitHub.

Preparación

Repositorio

Los estudiantes recibirán acceso al repositorio como colaboradores.

Repositorio Oficial
AlexSanderLopezOrcko/Practica4-Jueves
Abrir en GitHub ↗

Una vez recibido el acceso, clonar el repositorio e ingresar a la carpeta del proyecto:

Terminal
$git clone https://github.com/AlexSanderLopezOrcko/Practica4-Jueves.git $cd Practica4-Jueves

Crear rama de trabajo

Cada estudiante debe trabajar en su propia rama. La rama debe tener el siguiente formato:

Formato de rama
$git checkout -b practica4-TU-NOMBRE-COMPLETO

Por ejemplo:

Ejemplo
$git checkout -b practica4-AlexSanderLopezOrcko
⚠️ Importante
Todo el trabajo debe realizarse en la rama personal. No realizar cambios directamente sobre main.

Ejercicio 1 — HTML básico

10 pts

Objetivo

Recrear mediante HTML la estructura mostrada en la siguiente plantilla.

Plantilla

[IMAGEN DE REFERENCIA DEL EJERCICIO 1]

La página deberá contener los elementos mostrados en la plantilla. Entre ellos se encuentran:

  • Título.
  • Párrafos.
  • Imagen.
  • Enlaces.
  • Lista ordenada.
  • Lista desordenada.

Condiciones

  • Utilizar únicamente HTML.
  • Recrear la estructura mostrada en la plantilla.
  • Utilizar correctamente los elementos HTML correspondientes.
  • No utilizar CSS.
  • No utilizar JavaScript.

Revisa los elementos básicos de HTML utilizados durante las primeras clases: encabezados, párrafos, imágenes, enlaces y listas.

Ejercicio 2 — Tabla HTML

15 pts

Objetivo

Recrear mediante HTML la siguiente tabla.

Datos de la tabla

Estudiante Edad Carrera Semestre
Ana 21 Sistemas 6
Luis 23 Sistemas 8
María 20 Sistemas 5
Carlos 22 Sistemas 7

La tabla deberá contener correctamente los encabezados, filas, columnas y datos proporcionados.

Condiciones

  • Utilizar HTML.
  • No utilizar JavaScript.
  • La información debe coincidir con la tabla proporcionada.
  • La estructura debe ser equivalente a la tabla mostrada.
💡 Ayuda

Piensa en la estructura:

table
├── fila
│   ├── encabezado
│   └── encabezado
└── fila
    ├── dato
    └── dato

Los elementos principales que necesitas son <table>, <tr>, <th> y <td>.

Ejercicio 3 — JavaScript y eventos

15 pts

Objetivo

Crear la interacción mostrada en la siguiente plantilla.

Interfaz

[IMAGEN DE REFERENCIA DEL EJERCICIO 3]

La interfaz contará con un campo para introducir un nombre, un botón y un espacio donde se mostrará el resultado.

Al introducir un nombre y presionar el botón, deberá aparecer un saludo utilizando el nombre ingresado.

Por ejemplo:
Nombre: Pedro   [ SALUDAR ]   ➔   Hola, Pedro

Condiciones

  • Utilizar HTML para la estructura.
  • Utilizar JavaScript para la interacción.
  • Utilizar un evento para detectar el clic del botón.
  • El mensaje debe cambiar según el nombre introducido.
  • Utilizar JavaScript para modificar el contenido de la página.
  • No utilizar onclick directamente en HTML.
💡 Ayuda

Necesitarás obtener los elementos HTML desde JavaScript y escuchar el evento del botón.

Puedes revisar:

document.getElementById() y addEventListener()

Para cambiar un texto, revisa la propiedad:

textContent

Ejercicio 4 — Eventos + datos

20 pts

En este ejercicio se proporcionará un archivo con información:

ejercicio4/
├── index.html
├── script.js
└── datos.json

El archivo datos.json contiene los datos que deberán utilizarse desde JavaScript.

Objetivo

Leer los datos proporcionados y generar dinámicamente una tabla HTML para mostrar los precios de los combustibles (Gasolina, Diesel, GNV).

La tabla deberá ser generada desde JavaScript, utilizando los datos de datos.json.

Ejemplo de estructura de tabla:

País Combustible Precio
(Los datos se generarán aquí mediante JavaScript)

Condiciones

  • Utilizar el archivo datos.json.
  • Utilizar JavaScript para procesar los datos.
  • Crear dinámicamente una tabla HTML (<table>).
  • Mostrar los precios correspondientes a Gasolina, Diesel y GNV.
  • Manipular el contenido del DOM utilizando JavaScript.
💡 Ayuda

Para recorrer los datos del JSON puedes usar bucles como:

for o forEach

Puedes construir el HTML de la tabla como un texto (string) e insertarlo usando:

elemento.innerHTML

Ejercicio 5 — Consumo de API

20 pts

Objetivo

Consumir una API REST utilizando JavaScript y mostrar la información obtenida en una interfaz previamente preparada.

En este ejercicio se proporcionarán los archivos HTML y CSS:

ejercicio5/
├── index.html
├── style.css
└── script.js

El diseño de la interfaz ya estará preparado. No es necesario modificar el CSS. El HTML tendrá los elementos necesarios y sus respectivos id.

Interfaz

[IMAGEN DE REFERENCIA DEL EJERCICIO 5]

El trabajo principal consiste en implementar la funcionalidad mediante JavaScript.

API

Se utilizará la PokeAPI (https://pokeapi.co/):

API Endpoint
https://pokeapi.co/api/v2/pokemon/

La aplicación deberá obtener información de un Pokémon y mostrar como mínimo:

  • Nombre.
  • Imagen.
  • Tipo.

Condiciones

  • Utilizar fetch.
  • Realizar la petición desde JavaScript.
  • Utilizar los id proporcionados en el HTML.
  • Mostrar dinámicamente la información obtenida.
  • No modificar el CSS proporcionado.
  • No es necesario crear nuevamente la estructura HTML.
  • El objetivo principal es practicar el consumo de una API mediante JavaScript.
💡 Ayuda

La petición puede realizarse utilizando:

fetch()

Recuerda que la respuesta de una API debe convertirse a JSON. Revisa:

response.json()

Después podrás acceder a los datos obtenidos para mostrarlos en los elementos HTML.

Ejercicio 6 — PokeAPI + buscador

20 pts

Objetivo

Utilizar JavaScript para consumir la PokeAPI (https://pokeapi.co/) y buscar un Pokémon específico por su nombre.

Al igual que en el ejercicio anterior, se proporcionará una interfaz HTML y CSS previamente preparada:

ejercicio6/
├── index.html
├── style.css
└── script.js

El estudiante deberá implementar la funcionalidad únicamente mediante JavaScript.

Resultado Esperado

[RESULTADO ESPERADO DEL EJERCICIO 6]

La interfaz contará con un campo de texto (input) y un botón para filtrar/buscar.

Por ejemplo:
Nombre: [ Pikachu ]   [ FILTRAR ]

Al anotar el nombre del Pokémon y presionar el botón de filtro, se deberá consultar la API y mostrar la imagen del Pokémon encontrado junto con algunos datos que devuelva la API.

Condiciones

  • Utilizar fetch.
  • Utilizar la PokeAPI.
  • Utilizar un evento de click para el botón de búsqueda.
  • Mostrar la imagen y datos del Pokémon dinámicamente.
  • Utilizar JavaScript para manipular el HTML existente.
  • No modificar el CSS proporcionado.
💡 Ayuda

Para obtener el texto ingresado en el input puedes utilizar:

input.value

Para consumir la API y buscar el Pokémon por nombre necesitarás:

fetch()
